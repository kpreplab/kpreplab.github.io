# 한글 타자 연습 (귀화 작문)

귀화시험 앱의 동반 도구. 와이프가 작문 모범답안을 직접 타이핑할 수 있도록, 한컴타자연습 형태로
한글 자판 **자리연습 → 낱글자 → 낱말 → 단문 → 귀화 작문(장문)** 5단계를 연습하는 설치형 PWA.

- 라이브: (배포 후 여기에 주소 적기)
- 귀화앱 홈의 "타자 연습" 카드로 진입.

## 연습 모드 (5단계)
1. **자리 연습(position)** — 자모 하나씩, 자판 위치와 손가락을 익히는 위치 드릴.
2. **낱글자 연습(syllable)** — 자음+모음을 모아 한 글자씩 완성. 기본 글자 → 받침 글자 → 쉬운 낱말.
3. **낱말 연습(word)** — 비슷하게 생긴 실재 낱말을 빠르게 변별하며 정확히 치기.
4. **단문 연습(short)** — 짧은 문장 따라 치기(회원 로그인 후 사전평가 작문 + 인사·자기소개 문장).
5. **귀화 작문 연습(long)** — 귀화 종합평가 작문(200자) 모범답안. 두 가지 진입:
   - **따라 치기** — 모범답안을 화면 안내에 따라 그대로 입력.
   - **실전 쓰기** — 주제·작성 도움말만 보고 빈 화면에 자유 타이핑(오토마타·가상 키보드 동작, 타깃 비교 없음). 타이머·글자수(200자 게이지)만 측정하고, 완료 시 모범답안을 펼쳐 스스로 대조 + 잘함/보통/부족 자가확인 1탭.

## 특징
- **OS 한글 IME 불필요.** 물리 키(`event.code`)를 두벌식 오토마타로 직접 한글로 조합한다.
  자판이 익숙하지 않아도 화면이 "다음 누를 키 + 손가락"을 알려준다.
- 가상 키보드에 손가락 색상존 + 다음 키 하이라이트(구리 강조) + F/J 홈닷.
- 정답 판정은 타깃 문자열을 표준 두벌식 자모 키 시퀀스로 분해해 키 단위로 비교.
- **첫 실행 온보딩(1장):** 왼손=자음·오른손=모음, 한 글자=자모 조합(가 = ㄱ + ㅏ), 화면이 알려주는 키를 누르면 된다는 안내(4개 언어).
- **성장 표시:** 판마다 세션 로그를 쌓아 홈 상단에 "이번 주 X판 · 평균 N타 · 정확도 N%" 미니 요약, 완료 카드에 "지난 판 대비" 한 줄.
- **홈 진행 배지:** 각 모드 카드에 최고 기록("최고 234 · 98%") 또는 미연습 표시.
- **약한 키 보충:** 오타 시 "정답이었어야 할 자모"를 누적해, 완료 카드에 자주 틀리는 키 상위 5개 + [약한 키 보충 연습] 버튼(그 자모들로 만든 임시 위치 드릴, 기록 저장 안 함).
- **발음 듣기(TTS):** 자리·낱글자는 자모 단위, 낱말·단문·장문은 음절 완성 시 읽기(발음 토글 존중).
- 언어: **ko / zh / vi / th** 4개(상단 언어 버튼). 귀화앱 본체와 `nq_lang`으로 언어 상속·양방향 동기화.
- 통계: 시간 · 타수(타/분) · 정확도 · 오타.
- 딥링크: `#모드/번호` (예: `#long/0`). 모드 = position / syllable / word / short / long. 직접 열어도 회원 확인 후 진입한다.

## 저장 데이터 (localStorage, 기기별)
- `typing_best_v1` — 모드:idx별 최고 기록 `{speed, acc, date}`. 최고기록 판정은 **속도 경신 && 정확도 95% 이상**. (옛 숫자값은 읽을 때 `{speed:그값}`으로 하위호환.)
- `typing_log_v1` — 판 완료마다 `{m,i,s,a,e,d}` append, 최대 300개 FIFO. 성장 요약·지난 판 대비 계산에 사용.
- `typing_weakkeys_v1` — 오타 자모별 누적 카운트 `{jamo:count}`.
- `typing_onboard_v1` — 온보딩 1회 표시 플래그.
- `typing_lang` `typing_sound` `nq_lang` — 언어·발음 토글·귀화앱 공유 언어.

## 파일
- `index.html` `styles.css` `app.js` — UI·로직 (Molecular Precision 브랜드 토큰 적용)
- `hangul.js` — 두벌식 키맵 + 손가락 배열 + 한글 조합 오토마타(순수 함수, node 검증됨)
- `data.js` — 공개 빈 자리표시자. 작문 모범답안은 Supabase `questions` 테이블에서 `type=writing` 으로 회원만 읽는다.
- `../membership.js` `../supabase-config.js` — Supabase 회원 로그인과 권한 확인.
- `manifest.webmanifest` `sw.js` `icon*` — PWA (theme_color `#0D1B4C`)

## 검증
- `hangul.js`는 전체 한글 음절 11,172자 + 모든 작문 모범답안에 대해
  `compose(textToKeystrokes(s)) === sanitize(s)` 라운드트립을 통과.
- 배포 시 `sw.js`의 `CACHE` 숫자만 올리면 설치된 기기가 다음 접속 때 자동 갱신한다.
